This essay is an example. It lives in the `essays` folder of the Obsidian vault and uses most of what the site can do, so you can see each feature working and copy the Markdown.

## Writing

Write normally in Obsidian. *Italic*, **bold** and ==highlighted text== all work, and so do footnotes.[^1] Quotes become indented blocks:

> Every note in the vault stays private until its properties say it should be published.

Links between notes use Obsidian’s double brackets. This one goes to [[On Keeping a Commonplace Book|another example essay]], and this one to my notes on [[Meditations]] in the Library. A link to a note that isn’t published, like [[Welcome]], shows as plain text instead of a broken link.

## Tables

| In the note’s properties | On the site |
|---|---|
| `publish: true` | The note becomes a page |
| `tags: [writing]` | It’s listed under that topic |
| `pin: 1` | It’s shown first on the homepage |

## Versions

When you change an essay in a way that matters, commit it with a message starting with `rev:`, such as `rev: Rewrote the section on images`. The essay then gets a History page listing every version. Each version can be read as it was, next to a word-by-word comparison with the one before. Commits without `rev:`, like typo fixes, update the page without adding a version. This essay has only one version so far, so it has no History link yet.

## For readers

Select a passage and press “Email me about this” below: the email opens with the passage quoted. Press `/` anywhere to search, the 文A button to read the page in another language, and the moon for dark mode.
