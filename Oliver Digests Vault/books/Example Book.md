This is an example book note. It isn't on the site because `publish` is `false`.

Every note in this `books` folder is a book in the Library. Its properties hold the details: `author`, `published` (the year), `finished` (the date you finished it), `rating` (1–5), and `cover`. For the cover, drag an image into the `attachments` folder and set `cover` to its file name or to `[[cover.jpg]]`.

Whatever you write here becomes the book's notes page. If you leave the body empty, the book is still listed in the Library, just without a notes page.

> Quotes work well as blockquotes.
